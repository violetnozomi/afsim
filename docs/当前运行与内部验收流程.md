# AFSIM 网络资源管理器当前运行与内部验收流程

_适用代码：`feat/v0.11-model-service-facade` · 当前开发基线：`ae214dd`加未提交网关工作区 · 软件版本：`0.12.0`_

## 1. 文档目的

本文给出 AFSIM 网络资源管理器的单次运行命令、自动化内部预验收流程、人工界面检查项、
完成内容和未完成边界。执行结果只能用于内部 `PRE_ACCEPTANCE`，不能替代甲方目标环境、
正式接口、真实四网模块和安全部署条件下的最终验收。

验收状态含义：

| 状态 | 含义 |
| --- | --- |
| `IMPLEMENTED` | 代码和自动测试已经实现 |
| `PRE_ACCEPTANCE` | 已使用内部配置、固定场景或模拟接口验证 |
| `COMPONENT_ONLY` | 独立组件和单元测试完成，但尚未进入运行时主链 |
| `CUSTOMER_BLOCKED` | 必须等待甲方接口、样包、ABI 或目标环境 |
| `FINAL_ACCEPTANCE` | 使用甲方正式接口、样包和目标环境完成验收 |

- 已连接项目配置的 VNC 桌面；

### 4.4 算法路由逐跳人工验收

1. 打开“任务评估”，选择不同的源平台和目的平台，填写需要的带宽/时延/PDR门限；
2. 点击评估后，先核对文本中的“主路由逐跳”：`H1`开始、跳号连续、前一跳目的端点与
   后一跳源端点衔接，每跳显示当前链路/候选链路/网关转换；
3. 主路由存在时，态势图应显示黄色粗有向箭头；备选路由存在时，应先画青色细箭头，再叠加主路由；
4. 每条箭头必须与文本中同编号`Hn`对应，标签显示该跳网络；只有标为“候选链路”的跳使用虚线；
5. 跨域路由中，同一网关平台的入口端点→出口端点应显示为节点旁的带方向转换环，标注
   `Hn 入口网络→出口网络`，不应将网关前后平台直接跨接；
6. 主路由首节点保持绿色圈，末节点保持橙色圈；图例应同时包含当前链路、算法主路由、算法备选路由、
   候选跳和网关转换。

注意：这里的“真实”是指不遗漏地显示评估算法返回的每条有向边，不是显示仿真报文的实时转发轨迹。
