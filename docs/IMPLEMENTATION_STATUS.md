## 🗺️ 下一步

下一版本目标为`0.5.0-candidate-routing`：

1. 增加链路中断、拥塞和质量下降场景
2. 实现候选可建链边和当前图严格分离
3. 增加显式跨网网关能力
4. 增加一条确定性备选路由
5. 增加综合代价与完整稳定性评分

本阶段不自动执行建链、改频或路由操作。
