## 🗺️ 下一步

下一版本目标为`0.3.0-metrics`：

1. 从`WsfCommResult`提取有效RF字段
2. 建立消息关联键和三档滑动窗口
3. 计算排队时延、单向时延、PDR和利用率
4. 增加链路中断、拥塞和质量下降场景
5. 在GUI增加字段来源、有效性和时间

本阶段不自动执行建链、改频或路由操作。
