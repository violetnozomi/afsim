## 4. 合同主线

### 4.1 导航模型

合同要求支持卫星导航、惯性导航以及精度／误差数据。

当前责任解释：甲方功能包完成解算，本项目解析和标准化结果；是否需要本项目额外计算精度／误差仍待甲方书面确认。

### 4.2 数据链模型

需支持轮询、TDMA、宽带和卫通等数据链协议仿真，以及不同频点传输特性。

内部演示剖面只能形成PRE_ACCEPTANCE，不能替代真实协议或甲方模块终验。

### 4.3 通信能力

需接收作战区域、地形、气象、天象／电磁环境、平台姿态、通信参数和节点数，输出距离、速率、丢包率、时延、吞吐量和接入率。

没有环境输入时必须保持来源和置信度，不得伪造高置信度结果。

### 4.4 规划模型

合同要求规划文件加载、卸载、编辑、校验推演、分发和存储，以及机上／地面与动态入退网协同。单纯路径推荐不等于规划模型完成。

### 4.5 资源管理

合同表3-1有30条记录，对应26类不重复字段。重复关系为2／19链路可用性、15／21应答时延、16／22传输时延、17／23通信质量。

追踪必须保留30条，内部计算复用26类规范字段。

### 4.6 部署和设计

最低环境为X86四核以上、主频不小于1.0 GHz、内存不小于2 GB、硬盘不小于100 GB、百兆／千兆网卡，并支持甲方信息化／OA环境和小型局域网联试。

还要求异常日志、断电后再次正常启动、第三方模型兼容、模块化、高内聚低耦合和面向对象组件化。

## 5. 永久架构决策

- AFSIM核心零修改；
- 外部扩展仓库独立构建；
- 公共值对象不依赖Qt／AFSIM；
- 仿真线程不做文件I/O和复杂评估；
- GUI线程只消费不可变快照；
- 文件线程使用有界队列；
- 外部接口通过适配器转换；
- 内部、甲方、回放、参数化和派生数据区分来源；
- 所有指标带valid、unit、origin、confidence和sampleTime；
- 当前图、实际路径和候选图分离；
- 当前插件只读，不自动控制网络。

## 6. 指标语义

必须区分offered load、delivered throughput、相同消息生命周期口径的strict delivery ratio以及具有可靠发送分母的link PDR。

禁止把接收成功事件同时当成链路发送分母和分子，从而得到虚假100% PDR。

路径评估规则：

- 带宽取瓶颈；
- 时延逐跳累计；
- PDR当前按各跳条件独立乘积估计；
- 任何必需指标无效时不能判定满足；
- 当前图优先；
- 不应只检查一条最低时延路径。
