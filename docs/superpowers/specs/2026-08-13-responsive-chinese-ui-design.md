# Warlock 中文响应式界面设计

## 目标

在不改变 AFSIM 核心、JSON Schema、资源规划文件及合同接口英文编码的前提下，使网络资源管理器的可见反馈中文化，并允许各界面在远程桌面和小分辨率窗口中自由缩放。

## 设计

- 新增独立的界面文本转换组件。它只把枚举、原因码、字段名转换为中文显示文本，原始英文编码保留在括号或工具提示中。
- 通用表格从 `ResizeToContents` 改为 `Interactive`，列宽可拖动，长文本省略并通过工具提示查看全文，表格自身允许缩小并提供滚动条。
- 移除态势画布的 `620×480` 硬性最小尺寸；取消需求匹配表格的固定最小高度。
- 不修改核心 `ToString`、序列化器和上报器，确保甲方接口兼容。

## 验收

1. 资源规划状态、来源、置信度、降级等级、校验原因和字段名均显示中文。
2. 表格列可拖动，长成员列表不会撑大整个 DockWidget。
3. 缩小窗口时表格和态势画布继续收缩，必要时出现滚动条。
4. 既有 JSON 和 CSV 输出保持英文编码。
5. 中文映射测试、现有单元测试和 Warlock 插件构建通过。
