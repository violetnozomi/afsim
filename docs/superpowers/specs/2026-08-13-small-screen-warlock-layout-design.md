# Warlock小屏响应式布局设计

_网络资源管理器远程VNC小屏适配 · 2026-08-13_

## 目标

在不修改AFSIM核心、资源规划数据和评估算法的前提下，使网络资源管理器在小屏Windows
VNC窗口内能够访问全部资源规划操作和结果。

## 设计

- 顶部运行指标放入可折叠容器，默认收起，只保留标题和“运行概况”按钮。
- 资源规划的资源分配、业务需求、校验问题和推演结果拆成四个二级页签。
- 加载、卸载、保存、校验、只读推演和生成分发包按钮位于二级页签上方，始终可见。
- 点击校验后自动打开“校验问题”，点击只读推演后自动打开“推演结果”。
- 每张表独占页面剩余区域，保留水平和垂直滚动条，不设置固定最小高度。
- Dock建议初始尺寸由1120×760缩小为720×620；实际停靠尺寸仍由Warlock主窗口决定。

## 验证

- `NetworkResourceManager`目标必须成功编译。
- 22项固定回归不得退化。
- 25节点场景必须继续加载运行。
- 人工VNC检查：默认顶部收起；规划操作按钮可见；四个二级页签可切换；推演后自动显示结果。
