# 合同 30 项指标实现矩阵

_适用版本：0.11.x · 状态：PRE_ACCEPTANCE · 更新日期：2026-08-13_

## 验收结论

合同清单中的 30 行均已建立软件字段、计算或降级规则、中文界面位置和 JSON 上报出口。
其中第 2/19、15/21、16/22、17/23 是重复条目，因此对应 **26 类唯一能力**。这里的
“已实现”表示插件能够接收、计算、显示并上报该项，不表示 AFSIM 当前场景一定提供真实
Link-11、Link-16、卫通或 CDL 协议测量。

数据质量统一分为：`DIRECT`（AFSIM/甲方直接提供）、`DERIVED`（事件计算）、
`PARAMETERIZED_MODEL`（网络剖面）和 `ESTIMATED`（兼容降级）。所有估算值均为低置信度；
甲方后续提供同名有效字段时，插件保留实测值，不用估算覆盖。

## 本轮新增闭环

- `ContractMetricEnricher` 在统一快照入口执行，所以 AFSIM 实时快照、甲方 JSON 输入和回放
  输入遵循同一降级规则。
- 中文“网络成员”页新增“职责”；“窗口指标”页新增“队列占用率、ACK、RTT”。
- `nrm.snapshot.v2` 增加 `memberRole`、`availableFrequenciesHz`、`queueLimit`、
  `queueUtilizationPercent`、`ackDelayMs`、`responseDelayMs` 和 `rttMs`。
- `nrm_contract_metric_enricher_test` 验证默认补齐、数值口径以及实测值优先级。

## 验收限制

第一版默认队列上限为 128，ACK/响应/RTT 在没有事务标识时由单向传输时延估算，成员职责
可由命名规则推断。这三类字段只能用于演示和预验收。部署到甲方 AFSIM 后，可通过同一
强类型快照/JSON 适配层提供真实职责、队列容量和事务时延；有效输入会自动替代降级值。
