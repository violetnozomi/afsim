# AFSIM 2.9 source snapshot

This directory contains the local AFSIM source tree at
`afsim-2.9.0-kylin_v10_sp1_x86_64/swdev/src/`, including its build scripts,
source documentation, tests, and source-tree assets.

Archives, compiled libraries and executables, build directories, and runtime
outputs are excluded. The separate Qt/GDAL build environments, dependency
packages, and large runtime map resources are not included. Building requires
the corresponding external dependencies; this is not a ready-to-run distribution.

Original source files and license notices are preserved. See
`afsim-2.9.0-kylin_v10_sp1_x86_64/swdev/src/LICENSE.md` for the upstream terms.
